# DELHI SURAKSHA PATH

An AI-powered **women's safety route advisor for Delhi-NCR**, built entirely in Python.

Enter a start point, a destination and your travel time. The app shows **three routes**
(**Fastest**, **Safest**, **Balanced**) on a map, each with a **0-100 safety score** and
**plain-English reasons**. It also includes **SOS**, a **fake call** screen, **nearby safe
spots**, **helplines**, **live trip sharing** and **anonymous community reports**.

> **Safer does not mean safe. This supports, not replaces, 112 and official services.**
>
> The risk model is trained on a **synthetic** dataset generated by a script. It is a
> student project, not a factual statement about any place or person. Real incident data
> would be required before any real-world use.

## 1. What you need before starting

| Requirement | Notes |
|---|---|
| **Python 3.11 or 3.12** | Best compatibility with `osmnx 2.x` and `shap`. Python 3.13 may fail on `numba`/`shap`. |
| **~2 GB free disk space** | The OSM graph, packages and caches take space. |
| **Internet** | Only for the one-time OSM download and geocoding. After that the app runs offline. |
| **An editor** | VS Code is fine. |

**No paid API key is required.** Twilio SMS is optional; without it the SOS page shows a
copy-paste message instead. See section 8.

## 3. Setup on Windows

Open **PowerShell** in the project folder (right-click the folder -> *Open in Terminal*).

### 3.1 Check Python

```powershell
py -3.11 --version
```

If that fails, install Python 3.11 from <https://www.python.org/downloads/release/python-3119/>
and **tick "Add python.exe to PATH"** in the installer.

> If typing `python` opens the Microsoft Store, that is the App Execution Alias, not
> Python. Use the `py` launcher (for example `py -3.11`) instead, or turn the alias off in
> *Settings -> Apps -> Advanced app settings -> App execution aliases*.

### 3.2 Create and activate a virtual environment

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks the activation script:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

...then run the activate command again. You should see `(.venv)` at the start of the
prompt. (In `cmd.exe` use `.venv\Scripts\activate.bat` instead.)

### 3.3 Install packages

```powershell
python -m pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
```

### 3.4 Create your `.env`

```powershell
Copy-Item .env.example .env
```

## 4. Setup on macOS

Open **Terminal** in the project folder.

### 4.1 Check Python

```bash
python3 --version        # must be 3.11 or 3.12
```

If it is older, install with Homebrew (`brew install python@3.11`) or from python.org.

### 4.2 Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

You should see `(.venv)` at the start of the prompt.

### 4.3 Install packages

```bash

pip install -r requirements.txt

```

## 5. Verify the installation

From the project root, with the virtual environment active:

```bash
python scripts/run_checks.py
```

You should see green ticks for Python, every package, the folders, and the config. If
something is missing, the script prints the exact fix.

You can also run the smoke tests:

```bash
pytest -q
```

## 6. Run the app

```bash
py -3.11 -m streamlit run app.py
```

A browser tab opens at <http://localhost:8501>. The home page shows a **build status**
table: files that do not exist yet are marked "not built yet" until you finish the
matching phase. The placeholder pages describe what each one will do.

If `streamlit` is "not recognized", the virtual environment is not active, or use:

```bash
py -3.11 -m streamlit run app.py
```

## 8. API keys and no-key fallbacks

| Service | Needed? | Without a key |
|---|---|---|
| **OpenStreetMap / Overpass** | No key, free | Works. Please keep the downloads small and cached. |
| **Nominatim geocoding** | No key, free | Works. Set a real `NOMINATIM_USER_AGENT` in `.env`; results are cached in `data/processed/geocode_cache.json`. |
| **Twilio SMS** | Optional | The SOS page shows a ready-to-send message you can paste into WhatsApp/SMS yourself. |
| **Map tiles** | No key | Free OpenStreetMap tiles are used by default. |
| **Browser GPS** | No key | Optional. If the browser blocks location, you can type a landmark and the app geocodes it. |

To enable real SMS, create a free Twilio trial, then fill these in `.env`:

```dotenv
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_token
TWILIO_FROM_NUMBER=+12025550123
TWILIO_TO_NUMBER=+919876543210
```

Restart Streamlit after changing `.env`. On a trial account you can only message
**verified** numbers.

## 9. Troubleshooting

| Problem | Fix |
|---|---|
| `python` opens the Microsoft Store (Windows) | Use `py -3.11 ...`, or disable the app execution alias. |
| `Activate.ps1 cannot be loaded` | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, then activate again. |
| `pip` starts "Building wheel for shap / numba / geopandas" and fails | You are probably on Python 3.13+. Recreate the venv with 3.11 or 3.12. Also run `python -m pip install --upgrade pip setuptools wheel`. |
| `ImportError: DLL load failed` (Windows) | Install the **Microsoft Visual C++ Redistributable (x64)**, then reinstall the failing package. |
| `streamlit: command not found` | Activate the venv, or run `python -m streamlit run app.py`. |
| OSM download is very slow | The pilot box is small on purpose. Keep `PILOT_BBOX` in `config.py` tight; later you can expand it. |
| Nominatim returns 403 / no results | Put a real contact string in `NOMINATIM_USER_AGENT`, wait a minute, retry. |
| Map looks blank | Check your internet connection; OpenStreetMap tiles are fetched live. |
| Twilio error 21608 | Trial account: the destination number is not verified in Twilio. |

## 10. Privacy and responsible design (built into the app)

- **No account, no login, no name** is needed to plan a route.
- Trusted contacts are stored **only on your computer** (SQLite) and only if you press Save.
- A **"Delete my data"** button removes saved contacts and trip shares.
- Community reports are **anonymous** (no user id stored) and **lose weight over time**
  (90-day half-life), so a decade-old report does not label a place forever.
- The app never says "safe" or "unsafe". It shows a **caution level** with **reasons**.
- Every results page repeats: *"Safer does not mean safe. This supports, not replaces, 112
  and official services."*
- The interface is honest that the machine-learning model is trained on **synthetic** data.
